# Πώς μετατρέπουμε ένα αρχείο κώδικα ως αυτόνομο εκτελεστικό στην γλώσσα C;

Ο πιο κάτω τρόπος μπορεί να εφαρμοστεί σε διάφορες γλώσσες που ανήκουν στην
ίδια κατηγορία με την C.

Απλά θα χρησιμοποιήσω την συγκεκριμένη γλώσσα γιατί είναι αρκετά γρήγορη
στην διαδικασία μεταγλώττισης, εν αντιθέσει, για παράδειγμα, με την C++.

Στην αρχή ενός αρχείου πηγαίου κώδικα της γλώσσας C, γράψτε τον ακόλουθο
κώδικα:

```c
    #if 0
    set -e
    trap 'rm -f "$0.bin"' EXIT
    [ "$0" -nt "$0.bin" ] &&
    gcc -O2 -Wall -Wextra -Wpedantic -std=c11 "$0" -o "$0.bin" -s
    "$0.bin" "$@"
    exit
    #endif
```

Για να λειτουργήσει ο συγκεκριμένος μηχανισμός, αλλάξτε τα δικαιώματα του
συγκεκριμένου αρχείου με την βοήθεια του προγράμματος `chmod`:

```shell
$ chmod +x myfile.c
```

Τώρα, το μόνο που μένει να κάνετε είναι να τρέξετε το πρόγραμμά σας:
`./myfile.c`.

Ορίστε ολόκληρος ο κώδικας:

```c
#if 0
set -e
trap 'rm -f "$0.bin"' EXIT
[ "$0" -nt "$0.bin" ] &&
gcc -O2 -Wall -Wextra -Wpedantic -std=c11 "$0" -o "$0.bin" -s
"$0.bin" "$@"
exit
#endif

#include <stdio.h>

int main(void)
{
    const char* name = "stefanos82";
    printf("Hello, %s!\n", name);
    return 0;
}
```

Και η διαδικασία:

```shell
$ chmod +x myfile.c
$ ./myfile.c
Hello, stefanos82!
```

Και τώρα, ας εξηγήσουμε τι κάνει ο πιο πάνω κώδικας στο αρχείο μας.

Οι γραμμές

```c
#if 0
#endif
```

λένε στον preprocessor να αγνοήσουν τον κώδικα που βρίσκεται από την αρχή
ως το τέλος του `#if / #endif` condition.

Το γιατί δουλεύει είναι επειδή με την αλλαγή άδειας σε εκτελεστικό, τρόπον
τινά ξεγελάμε το σύστημα να το βλέπει ως shell script και όχι ως πηγαίο
κώδικα.

Άρα τις γραμμές μεταξύ του

```c
#if 0
#endif
```

τις βλέπει ως shell script, γι' αυτό δουλεύει.

Προχωράμε!

Μέσα σε αυτές τις συνθήκες καθοδηγούμε το σύστημα να διαγράψει το
executable με το όνομα `$0.bin` όταν λάβει χώρα το σήμα παγίδευσης (trap
signal) τύπου `EXIT`.

Με άλλα λόγια, κατά την έξοδο του προγράμματος (τερματισμός λειτουργίας και
διαγραφής διεργασίας), εκτέλεσε την εντολή `trap 'rm -f "$0.bin"' EXIT`.

Ακολούθως, έλεγξε αν αρχείο `myfile.c`, που στον μηχανισμό του τερματικού η
εντολή `$0` είναι το όνομα του αρχείου, κατά την διεργασία εκτέλεσης,
**είναι νεώτερο** του executable `$0.bin`, άρα είναι αλήθεια (`true`), τότε
εκτέλεσε την εντολή `gcc -O2 -Wall -Wextra -Wpedantic -std=c11 "$0" -o
"$0.bin" -s` για να δημιουργήσουμε το executable και ακολούθως το τρέχουμε
δεχόμενοι και παραμέτρους ως επιλογή: `"$0.bin" "$@"`.

Τέλος, καλούμε την έξοδο από το κέλυφος μας (shell).
